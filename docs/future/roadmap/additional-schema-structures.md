in real-world usage i've discovered a handful of new schema types that are starting to emerge.

the document obviously is designed to contain "a prompt" that describes a chunk of work to be thought about and integrated into a project. but sometimes the card needs a more thorough description or a justification for the work, which should be kept as separate material from the prompt itself.

also, in working with cross-team cards, there can be some amount of "back and forth" in working out what a roadmap item should contain.

we should consider how the schema for cards can accomodate these.
